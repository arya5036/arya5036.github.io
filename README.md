# Arya Sheikhi

Static personal contact page for <https://arya5036.github.io/>.

The site uses plain HTML, CSS, and JavaScript. All assets are local; there are no analytics, cookies, external fonts, or runtime dependencies.

## Files

- `index.html` — identity, contact actions, and professional links
- `style.css` — responsive dark theme and reduced-motion styles
- `script.js` — procedural SVG waves, desktop parallax, and QR expansion
- `portrait-*.webp` — cropped and compressed portrait, with image metadata removed
- `qr.svg` — QR code for the canonical website URL
- `arya-sheikhi.vcf` — vCard 3.0 contact file

Serve the repository root with any static HTTP server. GitHub Pages should publish the root of `main`.

To add a CV later, upload a real PDF and add a labeled link at the CV comment in `index.html`.
